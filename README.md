# Netflix-home-page-clone

---

### **Project Title:** Netflix Home Page Clone

### **Project Description:**

Recreated the front-end design of Netflix's home page using **HTML, CSS, and JavaScript**, replicating its layout, styling, and responsiveness. The project showcases skills in UI design, layout structuring, and responsive web development.

---

### **Key Features:**

* **Layout & Design:**

  * Built a pixel-perfect clone of Netflix’s landing page including the header, hero section, background image/video, and sign-in form.
  * Used CSS Flexbox and Grid for structured, responsive design.

* **Styling & Animation:**

  * Applied custom CSS to mimic Netflix’s look and feel with dark-themed UI, hover effects, and styled buttons.
  * Added smooth transitions and media queries for mobile responsiveness.

* **Interactivity:**

  * Integrated basic JavaScript for UI behaviors like toggling menus and validating sign-in form inputs.

---

### **Technologies Used:**

* HTML
* CSS
* JavaScript (for interactivity)

---

### **Outcome:**

* Successfully created a responsive clone of the Netflix home page to demonstrate front-end development skills and attention to detail in UI replication.
